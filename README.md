# दलालनामा — स्वतंत्र मराठी न्यूज पोर्टल

Independent mobile-ready Marathi news portal, using the original Dalalnama black-red-yellow identity and an eSakal-inspired layout without ads.

Live URL when Pages is enabled: https://catonpe-droid.github.io/Dalalnama/

## Publishing

The GitHub Actions workflow builds article and category pages from `data/news.json` and `data/layout.json`. Enable **Settings → Pages → Source: GitHub Actions**. Do not store credentials here. A separate Cloudflare Worker and new credentials must be set up before the CMS can publish; do not reuse Lokhit Maharashtra secrets.
